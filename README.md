# Smart Image Analyzer

A Computer Vision project that classifies animals 
and detects dominant colors in images.

## Features
- Animal Classification (Cats, Dogs, Horses)
- Dominant Color Detection
- User Friendly GUI

## Technologies Used
- Python
- TensorFlow / Keras
- MobileNetV2 (Transfer Learning)
- KMeans Clustering
- Tkinter (GUI)

## Model Accuracy
- Training Accuracy: ~95%
- Validation Accuracy: ~93%
